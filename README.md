# Insurance RAG Intelligence Platform

A production-oriented **Retrieval-Augmented Generation (RAG)** system for insurance knowledge retrieval, designed to explore, implement, and evaluate modern RAG techniques.

## 🎯 Project Goals

* Build an end-to-end RAG pipeline using **LlamaIndex**.
* Explore document parsing, chunking, embeddings, and indexing.
* Implement vector, BM25, and hybrid retrieval.
* Experiment with query transformation and reranking.
* Generate grounded answers with source citations.
* Evaluate retrieval and generation quality using standard RAG metrics.
* Compare different RAG strategies through controlled experiments.

## 🛠️ Planned Tech Stack

* **Python**
* **LlamaIndex**
* **Qdrant**
* **FastAPI**
* **PostgreSQL**
* **RAGAS**
* **Docker**
